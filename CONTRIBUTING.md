# Contributing to Prezent Prep Hub

Thank you for your interest in contributing to **Prezent Prep Hub**!

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/z20628425-hash/PresentPreb-Hub-.git
   cd PresentPreb-Hub-
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Copy `.env.example` to `.env` and configure your Gemini API Key:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Start the Development Server:**
   ```bash
   npm run dev
   ```

## Guidelines

- Follow existing TypeScript and React best practices.
- Use Tailwind CSS utility classes for layout and styling.
- Run `npm run lint` and `npm run build` to verify code quality before pushing.
- Submit Pull Requests with a concise description of changes.
