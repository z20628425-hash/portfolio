# Changelog - Prezent Prep Hub

All notable changes to this project will be documented in this file.

## [2.5.0] - 2026-08-13
### Added
- **IELTS AI Examiner Practicum**: Integrated Gemini-powered IELTS Speaking Part 1-3 and IELTS Writing Task 1-2 evaluation with real Band Score generation and examiner feedback.
- **Leaderboard Module**: Built `LeaderboardModal` with top 3 podium displays and rank tracking for all users.
- **Admin Panel Screen**: Added `AdminScreen` with system stats, course/test management, and analytics.
- **Rate Limiting & Health Check Endpoints**: Added `/api/health`, `/api/ielts/speaking`, `/api/ielts/writing` with express rate-limiting protection.
- **Language Switcher (i18n)**: Multi-language header selector (`UZ`, `RU`, `EN`).
- **PWA Manifest & Documentation Suite**: Added `manifest.json`, `docs/API.md`, `docs/ARCHITECTURE.md`, `docs/DEPLOYMENT.md`, `CONTRIBUTING.md`, and `LICENSE`.
